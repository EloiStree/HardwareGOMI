# HardwareGOMI

> Documentation on how to use GOMI and AB Input with the hardware I own.

I designed a package abstraction in Godot called **Boolean Analog (AB Input)**:   
https://github.com/EloiStree/2026_08_27_gdp_bool_analog_dictionary   

Considering that most inputs can be represented as a **trigger, boolean, or analog (float)**, the aim is not to merge inputs but to provide an option to associate actions as text with those inputs.    

You can then interpret those actions with GOMI or your GDScript.   

This Git repository is a collection of examples using the hardware I own.


## Trigger Event

Listen to a device emitting an event, rather than a button boolean or analog float.

```text
godot_mouse ♦️ trigger♦️ MOUSE_SCROLL_UP ♦️ cmd:log SCROLL UP
```

* `godot_mouse`: Name of the device generated by the Godot code.
* `trigger`: Tag to notify that this line represents an event.
* `MOUSE_SCROLL_UP`: Unique event ID generated in the Godot code by the device or developer.

## Boolean Value

Listen to a gamepad button changing to `true` (pressed) or `false` (released).

```text
Xbox One S Controller|S0|B0 ♦️ true ♦️ cmd:log bool:xbox_a:true
Xbox One S Controller|S0|B0 ♦️ false ♦️ cmd:log bool:xbox_a:false
```

* `Xbox One S Controller|S0|B0`: Unique device input ID.

  * `S0`: Spawn order `0`, meaning that this was the first input received with this name.
  * `B0`: Means that this is Godot's device button `0` in the Godot Engine code.
* `true`: The command must be triggered when the button becomes `true` (pressed).
* `false`: The command must be triggered when the button becomes `false` (released).

## Analog Value

```text
mpk mini play|an|0|0|71 ♦️ in ♦️ 80 ♦️ 127 ♦️ cmd:log bool:right_mkp_strong:true
mpk mini play|an|0|0|71 ♦️ out ♦️ 80 ♦️ 127 ♦️ cmd:log bool:right_mkp_strong:false
mpk mini play|an|0|0|72 ♦️ in ♦️ 0 ♦️ 0 ♦️ cmd:log bool:right_mkp_light:false
```

* `mpk mini play|an|0|0|71`: Generated unique input ID assigned by the developer to the note button.
* `in`: The action must be relayed when the value of this analog input is between or equal to the minimum and maximum values.
* `out`: The action must be relayed when the value of this analog input is outside the minimum and maximum values.
* `80`, `127`: Minimum and maximum values. These can be swapped if the setup is reversed.
* `in`, `0`, `0`: The action is triggered when the value is equal to `0`.
